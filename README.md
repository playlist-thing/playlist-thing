# playlist-thing

A playlist manager for radio DJs.

- Prepare your playlists before a show. Gather song metadata from different sources. Add notes to tracks.
- playlist-thing works offline. All playlists and settings are stored in your browser.

**playlist-thing** does not...

- ...manage your song library.
- ...deal with audio files. Only metadata like links to tracks can be stored here.

## Development

```bash
cp .env.example .env.development
npm install
npm run dev
```
